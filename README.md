# 🍸 Барвиха — обучалка

Веб-приложение для обучения: барная карта, осеннее предложение, «Синергия вкуса», тех. карты с граммовками, ПФ, вино, крепкое, методичка и тренажёр.

**Ссылка:** https://ЛОГИН.github.io/barvikha/ (точный адрес — в Settings → Pages)

## Как поставить на iPhone
1. Открой ссылку **в Safari**.
2. «Поделиться» (квадрат со стрелкой) → **«На экран «Домой»»** → «Добавить».
3. Запускай с иконки: на весь экран, без адресной строки, работает без интернета (после первого запуска).

Android (Chrome): меню ⋮ → «Добавить на главный экран».

## Telegram (по желанию)
1. @BotFather → `/newbot` → имя и username бота.
2. `/setmenubutton` → выбери бота → отправь ссылку → название кнопки, например «Обучалка».
3. В чате с ботом слева внизу появится кнопка — приложение откроется прямо в Telegram. Сервер для бота не нужен.

## Обновление
Загрузи новые `index.html` и `sw.js` с заменой (Add file → Upload files). У всех, кто поставил приложение, при следующем запуске появится плашка «Вышло обновление» → «Обновить».

Особенность iOS 26: при холодном запуске тёмных веб-приложений может мелькнуть белый кадр — это баг Safari (WebKit #311569), а не обучалки.
